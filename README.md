# Sudoku

Simple Sudoku generator/solver with a small Pygame GUI.

## Files
- `sudoku.py` — Sudoku generation, validation, solving, and difficulty logic
- `GUI_sudoku.py` — playable graphical Sudoku game

## Requirements
- Python 3
- `pygame`

Install:

```bash
pip install pygame
```

## Run

```bash
python GUI_sudoku.py
```

## Notes
- Generates a valid Sudoku puzzle with a unique solution.
- Includes difficulty levels, pencil notes, and lives.
